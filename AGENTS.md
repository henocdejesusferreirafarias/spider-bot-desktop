# AGENTS.md

SpiderBOT desktop client (Electron). Standalone repo extracted from the monorepo (issue #1, Wave 6).

Rules:

- This repo is the desktop **client** only. It talks to the API for license/token validation and public routes — never embed admin or landing code here.
- Shared contracts come from `@spider-bot/licensing-contracts`, pinned by Git tag (`#v1.1.x`). Do not vendor a copy; bump the tag to upgrade.
- `native/license-core` (Rust/napi) stays in this repo. Its build artifacts (`index.js`, `index.d.ts`, `*.node`) are generated by `napi build` and are not committed.
- `patches/socks+2.8.9.patch` is required (fixes a SOCKS5 crash via proxy-chain). It is applied by `patch-package` on `postinstall` — do not drop it.
- Emergency browser kills MUST be scoped to a single profile's `user-data-dir` via `forceKillProfileBrowser` (`browser-process-kill.ts`). Never `taskkill /IM chrome.exe` — it kills every profile *and* the user's own Chrome. See [ADR 0001](docs/adr/0001-kill-escopado-de-processo-do-navegador.md).
- Record relevant technical decisions as ADRs under `docs/adr/` (context → root cause → decision → verification) so the next dev/agent inherits the *why*.
- Verify before pushing: `npm install` (runs patch-package + napi build + Python setup), then `npm run check` and `npm test`.
- Release artifacts must be Windows code-signed; the release workflow requires the signing secrets/vars (see README).
